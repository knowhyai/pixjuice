How to cut a sprite sheet

  1. Upload a PNG sprite sheet — drag & drop it onto the page or browse for the file. Nothing is uploaded to any server.
  2. Slice it: set columns × rows or the cell size (with offset and spacing), or press auto-detect and PixJuice finds the frames through the transparent gaps. Click cells to drop them from the animation and ‹ › to reorder.
  3. Preview & export: set the FPS, loop or ping-pong, then download an animated GIF, a ZIP of PNG frames, a re-packed sheet, or the XML/JSON atlas for your engine.

Sprite sheet FAQ

What is a sprite sheet?

A sprite sheet is a single image that packs every frame of an animation (or many different sprites) into a grid. Games load it once and draw sub-rectangles out of it, which is much faster than loading hundreds of small files.

How do I turn a sprite sheet into a GIF?

Slice the sheet here, set the playback speed with the FPS slider, and press animated GIF. The GIF keeps transparent pixels, so the preview looks right on any background. No software to install — it all happens in your browser.

How does auto-detect work?

It looks for columns and rows that are fully transparent — the gaps between frames — and turns those bands into a grid: cell size, count, offset and spacing. If your sprites touch each other with no gaps, set the grid by hand instead.

Which engines can use the XML and JSON exports?

The XML is the Sparrow/Starling <TextureAtlas> format (also read by Cocos2d and many frameworks). The JSON follows the TexturePacker hash format used by Phaser, PixiJS and Godot imports.

Is my sprite sheet uploaded anywhere?

No. The cutter runs entirely client-side: the image is decoded, sliced and re-encoded in your browser, and the downloads are generated locally too.
