01 Animated UI

Kubai Icons ↗

Rounded icons that respond to hover or click.

Style & count
1,000+ rounded duotone and line SVG micro-animations, or 2,800+ with badged and slashed variants.
Formats & download
Copy or download individual static SVGs and PNGs, or get ZIP collections. React, Vue and vanilla JS packages are available.
License & commercial terms
MIT for icons and npm packages. Commercial use is allowed. When copying or redistributing, retain the copyright and permission notices. The source-available Skill and all-rights-reserved website have separate terms.
Best for
Dashboards, web tools and interactive menus that need cohesive micro-animations without Lottie.

02 Animated UI

AnimateIcons ↗

Hand-crafted motion for familiar interface shapes.

Style & count
About 1,500 stroke-animated UI icons using Motion, with Lucide and free Hugeicons shapes and hover or programmatic triggers.
Formats & download
React, Vue, Angular and vanilla JS via @animateicons/vanilla. Use npx animateicons add to copy individual icons.
License & commercial terms
MIT for commercial use. When copying or redistributing, retain the copyright and permission notices. Retain applicable notices in THIRD_PARTY_NOTICES.md for Lucide (ISC), Feather (MIT) and Hugeicons Free (MIT).
Best for
Game menus and tool interfaces that use React, Vue or vanilla JS.

Lucide-style motion tuned one icon at a time.

MIT allows personal and commercial use. When copying or redistributing, retain the copyright and permission notices. The README asks users to avoid redistributing or reselling demos and tutorials as-is.

05 Game & Pixel

Game-icons.net ↗

A wide-ranging library of game symbols.

Style & count
4,200+ static silhouettes and flat vectors for weapons, spells, potions, status effects, sci-fi and dice.
Formats & download
Customize colors and backgrounds on the site, then download individual SVGs or PNGs or get the full pack.
License & commercial terms
Mostly CC BY 3.0, which allows both commercial and noncommercial use and requires author attribution for both, for example “Icons made by {author}.” A few contributors use CC0, which requires no attribution. Check each icon’s author and license.
Best for
RPG skill bars, roguelike inventories, buff indicators and quick prototypes.
GitHub ↗ License details ↗
